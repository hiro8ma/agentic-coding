# アンチパターン

教材は 12 の名前を挙げ、God Agent だけ症状を詳しく書く。ほかの定義と兆候はこのスキルの解釈で、対応するチェック項目に紐づけた。
教材の中でも数値の目安はそろっていない（A-2 はツール 5 個以下、God Agent の症状は 10 個以上）。数値は目安として扱う。

| 名前 | 定義 | 兆候 | 項目 |
| --- | --- | --- | --- |
| God Agent | 1 つのエージェントが多くの責務とツールを抱える | 責務を 1 文で言えない。Instruction が数千トークンに膨らむ。ツールが 10 個を超える。応答が不安定で、ときどき的外れになる。1 つの修正がほかの機能に波及する。テストのケースが増え続ける | A-1、A-2、A-6 |
| Prompt Spaghetti | Instruction に規則、例外、手順が積み重なり、互いに矛盾する | 同じ主題が離れた場所に出てくる。追記ばかりで削除が無い | A-6 |
| Memory Amnesia | 本番で揮発するセッションやメモリを使い、会話や学んだことが消える | `InMemorySessionService` が本番の経路にある | O-5 |
| Infinite Loop | 同じツールを同じ引数で呼び続ける | 同じ span が 1 つの trace に並ぶ。ADK の既定の上限（Python 500、Go なし）に任せている | O-4 |
| Token Burn | 入力が膨らみ、費用が想定を大きく超える | 1 件あたりの入力が会話の長さに比例して伸びる。ループの上限が無い | C-3、C-4、O-4 |
| Security Afterthought | 認証、権限、監査を後から足す | Agent Card で認証を宣言しただけでサーバーが検証しない。監査が拒否を記録しない | S-1〜S-8 |
| Chatty Agents | エージェント間のやり取りが多く、呼び出しと入力が増える | 振り分けの判断が 2 段になっている。委譲の度に会話の全体を渡している | A-3、C-1 |
| Phantom Context | モデルやリモートのエージェントが見ていると思い込んだ情報が、実は渡っていない | State に置いた値を Instruction が参照していない。A2A のリモートに State を渡したつもりでいる | A-4 |
| Monolith Deployment | 負荷や変更の頻度が違うエージェントを 1 つにまとめてデプロイする | 1 つの変更で全エージェントが再デプロイされる | A-5 |
| Blind Delegation | 委譲した先の振る舞いと結果を確かめずに信じる | リモートの入力待ちが `AgentTool` で空の結果になっても気づかない。リモートが書いた金額をそのまま承認に使う | A-4、S-6 |
| Config Drift | 環境ごと、版ごとの設定や既定値がずれ、誰も把握していない | 再試行、本文の記録、ループの上限を既定値に任せている。版を上げてもテストを流し直さない | O-1、O-3、O-4 |
| Eval Neglect | 評価を回さない、または回しても結果を読まない | 評価の CLI の終了コードだけを見ている。評価セットが実装とずれている | Q-1〜Q-5 |
