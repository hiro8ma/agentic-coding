# 投稿の型

目的に合う型を 1 つ選び、要らない欄は消して使う。

## 型（依頼の例）

```
*お願い: ○○の確認（期限: 7/15 12:00）*

△△のため、○○の確認をお願いします。

*背景*

• なぜ今必要か（1〜2 文。リンクがあれば貼る）
• 確認しないと何が困るか

*お願いしたいこと*

1. □□を確認する
2. 問題があれば本スレッドに返信する

*完了後の流れ*

• 確認していただいたら、私が◇◇を進めます
• 結果はこのスレッドで共有します

*相談先*

• 期限で難しければ、このスレッドで教えてください
```

## 型（判断を求める例）

```
*相談: ○○の進め方（判断の期限 7/15 12:00）*

○○は A 案を推奨します。

*理由*

• □□（数値や事実）
• □□

*懸念点*

• △△の場合は◇◇になります

*判断してほしいこと*

• A 案で進めてよいか
```

## 型（進捗報告の例）

```
*報告: ○○の進捗（対応不要）*

○○は予定どおり進んでいます。

*現状*

• 完了 □□
• 未完了 □□

*課題*

• △△（なければ「なし」と書く）

*次のアクション*

• 7/16 までに◇◇を行います
```

## 型（依頼への返信の例）

```
確認しました。着手は 7/14 で、7/16 12:00 までに素案を出します。

*こう理解しました*

• やること　□□を△△の形にまとめる
• 狙い　◇◇の判断に使う（違っていれば教えてください）
• 完成度　7/16 は 3 割の素案、7/18 に 8 割

*確認したいこと*

• 「なるはや」は 7/18 中でよいですか

*不安な点*

• ○○は初めて扱うので、素案の時点で方向を見てください
```

## 型（会議のまとめの例）

```
*共有: ○○会議のまとめ（担当の方は期限を確認してください）*

*決まったこと*

• □□は A 案で進める
• △△は今回は見送る

*次のアクション*

• A さん　資料をまとめる　7/16 まで
• B さん　検討結果を共有する　7/18 まで

*決まらなかったこと*

• ◇◇の費用負担　見積もりが未着のため。C さんが 7/17 までに取り寄せ、次回 7/20 に決める
```

## 型（会議の案内の例）

```
*案内: ○○の進め方を決める会議（7/15 14:00〜14:30）*

□□を A 案と B 案のどちらで進めるかを決めます。

*今日のゴール*

• どちらの案で進めるかを決める。費用の細部は扱わない

*議題（優先の順）*

1. 2 案の比較（15 分）
2. 進める案の担当と期限（10 分）
3. 時間が余れば、△△の扱い

*事前に見てほしいもの*

• 比較の資料（リンク）。A 案の費用が高い理由は 3 ページにあります
```
