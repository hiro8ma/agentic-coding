# 形式ごとに測るべき指標

目視は見えている範囲しか検証しない。
画面では正しく見えるのに、その形式の要件を満たしていないという壊れ方がある。

| 形式 | 目視で見えるもの | 測るべき指標 |
|---|---|---|
| PDF | レイアウト・文字 | **ページ数**、用紙サイズ、余白が印刷範囲に収まるか |
| 動画 | 各フレームの見た目 | 尺、フレームレート、音声トラックの有無、無音区間 |
| 画像 | 内容 | 解像度、色空間、ファイルサイズ、透過の有無 |
| 音声 | 波形 | サンプリングレート、チャンネル数、クリッピング |
| CSV / TSV | 先頭数行 | 行数、列数の一貫性、文字コード、区切り文字の混入 |
| JSON | 整形された表示 | スキーマ適合、null と欠損の区別、数値の精度 |
| HTML メール | ブラウザでの表示 | 主要クライアントでの崩れ、インライン CSS 化 |
| ログ | 直近の数行 | 総量、レベル別の内訳、機密値の混入 |
| 集計値 | 合格率・スコア | **内訳**。片側が全滅していないか |

## PDF のページ数を数える

外部ツールなしで数えられる。

```python
import re
raw = open("out.pdf", "rb").read()
counts = [int(x) for x in re.findall(rb"/Count\s+(\d+)", raw)]
pages = max(counts) if counts else len(re.findall(rb"/Type\s*/Page[^s]", raw))
```

画面キャプチャでは A4 の紙面境界が写らないため、
`--screenshot` で確認しただけでは 2 ページに割れていても気づけない。

## 集計値の内訳を見る

合格率が中途半端な値のとき、まず疑うのは片側の全滅になる。

```
4/8 通過
  → 通過した 4 件はすべて「発火すべきでない」側
  → 「発火すべき」側は 0/4
  → 機構が一度も動いていない
```

肯定側と否定側の件数が、通過数と一致していないかを見る。
一致していれば、片側が自動的に正解になっているだけの可能性が高い。
