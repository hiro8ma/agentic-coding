# デフォルト単価テーブル

Web 制作でよく使う品目の標準単価。
ユーザーが金額を指定しなかった場合はここの値を使う。

単価はすべて税抜。自社の料金体系に合わせるときは、このファイルを直接編集する。
品目の追加・削除・単価の変更・カテゴリの追加はすべてこのファイルだけで完結し、
スクリプトの修正は要らない。

## 単位の使い分け

| 単位 | 使うとき |
|---|---|
| 式 | 一括で請ける作業。分割しても意味がないもの |
| ページ | ページ数に比例するもの |
| 本 / 枚 / 点 / 件 / 記事 | 成果物の個数が数えられるもの |
| 人日 | 工数に比例し、成果物の個数で測れないもの |
| 月 | 継続契約 |
| ％ | 他の品目の合計に対する比率。ディレクション費のみ |

ディレクション費を ％ で置いているのは、制作費の規模に比例して手間が増えるため。
金額を直接指定したい場合は、単位を「式」に変えて単価を入れる。
