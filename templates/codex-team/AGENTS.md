# AGENTS.md

このリポジトリで作業するコーディングエージェント向けの指示
承認が要るコマンドは`.codex/rules/team.rules`と`.claude/settings.json`で止めている。ここには判断の基準を書く

## コマンド

<!-- ビルド、テスト、lintのコマンドをこのリポジトリのものに置き換える -->

```bash
make test
make lint
```

## 変更時の注意

- ログ、エラーメッセージ、テストのfixtureに個人情報（氏名、メールアドレス、電話番号、住所）と認証情報を書かない
- DBのマイグレーションは追加だけにする。列やテーブルの削除、型や名前の変更は、読む側のコードを先に直してから別の変更で行う
- 公開APIのリクエストとレスポンスの形を変えるときは、既存の呼び出し元が動き続けることを確かめる
- 依存関係の追加と更新は、機能の変更と別のコミットにする
- マージ、強制push、本番環境への反映は人が行う。エージェントは変更と確認の手順までを返す

## Review guidelines

- ログやエラーに個人情報や認証情報が出る変更はP1として扱う
- マイグレーションに列やテーブルの削除、型や名前の変更が含まれていないか確かめる
- 認証が要る経路に、認証と認可の両方の検査があるか確かめる
- 変えた挙動にテストがあるか確かめる
- 整形やlintで検出できる指摘はCIに任せ、レビューでは出さない
