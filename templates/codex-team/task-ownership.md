# AIと人の作業分担

- 対象の問題は〈誰が何に困り、今回何を変えるか〉
- 対象工程と変更範囲は〈調査 / 設計 / 実装 / 検証など〉
- 責任を持つ担当者（owner）は〈結果を受け取り、完了と次工程への移行を判断する人〉

## Delegate

- AIに任せる作業は〈入力 / 作業内容 / 期待する出力〉
- 参照する正本は〈実在する相対パスや資料〉
- AIが決めてよい範囲は〈既存規約で決まること / 今回合意した判断〉

## Review

- 人が確認する対象は〈変更や出力と、確認する理由〉
- 確認する人は〈担当者〉、判断基準は〈品質 / 互換性 / 利用者への影響〉
- 品質ゲートは〈受け入れ条件 / 検証方法 / 必要な証拠〉
- 未実行の検証は〈理由 / 次に確認する方法と担当者〉として残す

## Own

- 人が持つ判断は〈要件 / 許容するリスク / 公開や本番への反映など〉
- ownerが受け取る成果は〈採否を判断できる変更内容と証拠〉
- 確認する人とownerが異なる場合の引き継ぎ先は〈担当者と受け渡す結果〉

## 中断と結果の反映

- 中断して相談する条件は〈仕様の矛盾 / 権限不足 / 予算超過など今回必要な条件〉
- 相談先は〈担当者〉、再試行の上限は〈回数または時間と、到達時の扱い〉
- 結果を戻す場所は〈Issue / 仕様 / テスト / 運用手順など〉
- 戻す内容は〈採否と根拠 / 検証結果 / 残る問いと次の担当〉
- 未確定の必須欄は未完了とし、ownerが確定するまで該当作業を開始しない
