# 用語集の例

架空の取引先「架空商事」との仕事を例にした用語集
社名と語はどれも架空のもの

| 使う語 | 使わない語 | 除く語 | 対象 | 使う場面 | 期待する判断 |
|---|---|---|---|---|---|
| | 様 | 仕様 / 模様 / 同様 / 多様 / 様子 / 様式 / 様々 / 一様 / 様相 / 異様 | commit / pr | コミットメッセージと PR のタイトル / 本文で、取引先の社名に触れるとき | 社名だけを書く（架空商事）、チャットとメモでは敬称を付けるので docs には広げない |
| 発注 | オーダー | オーダーメイド | all | 架空商事に商品を頼む行為を書くとき | 頼む行為は発注、頼まれた側の記録は受注と書き分ける |
| 見積書 | 見積もり書 / 御見積書 | | docs / pr | 架空商事に出す金額の書類を指すとき | 書類の名前は見積書に揃え、金額を見積もる作業は見積もりと書く |
| サーバー | サーバ | | all | 機械やプロセスを指すとき | 長音の付いたサーバーに揃える |
| main | master | | all | 既定のブランチを指すとき | 既定のブランチは main と書き、ほかのリポジトリの master を指すときはコードの書式で囲む |
